🎬 YouTube Video Analyzer

Transcreva e resuma vídeos automaticamente com inteligência artificial.

Sobre o Projeto

Este projeto utiliza Python, OpenAI GPT e Whisper para baixar o áudio de vídeos do YouTube, gerar uma transcrição e criar um resumo inteligente do conteúdo.

🚀 Abrir Aplicação 💻 Ver Código

Funcionalidades

  • 🔗 Insira o link de qualquer vídeo do YouTube
  • 🎧 Baixa e converte o áudio automaticamente
  • 🗣️ Transcreve com o modelo Whisper (OpenAI)
  • 🧠 Gera resumo inteligente com GPT-4
  • 💾 Exporta resultados em texto
